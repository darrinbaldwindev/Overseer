## 2. GlobalShopCo

### Publishable now
- Brand/category-level utility content.
- “How we choose products” transparency.
- Home organisation/problem-solution education.
- Category comparisons that do not assert unavailable product facts.
- Trust content about evidence-first product selection.

### Blocked / qualified
- Exact SKU promotion without current product evidence.
- Free-delivery claim unless current customer offer supports it.
- Delivery-time, warranty, material/safety or stock claims without evidence.
- Margin-driven product promotion where freight evidence is missing.

### Unblock evidence
- exact supplier/listing identity;
- current stock/availability;
- current retail price;
- freight/delivery evidence;
- returns/warranty facts;
- relevant safety/specification evidence;
- image rights.

### First safe sequence
1. Useful products, carefully selected.
2. What we check before recommending a product.
3. Home organisation educational carousel.
4. Problem-solution short video.
5. Category comparison.
6. First exact product spotlight only when Level 3 evidence-cleared.

## Release rule

No release packet authorises publishing by itself. Before any publish action, confirm:
1. campaign ID exists;
2. asset ID exists;
3. evidence class is current;
4. copy is channel-adapted;
5. CTA destination is correct;
6. no blocked claim remains;
7. performance receipt can be created after publication.
