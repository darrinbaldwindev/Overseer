# AgentOS Free-AI Value Proposition

**Date:** 2026-09-12
**Role:** Marketing Overseer
**Status:** OWNER-APPROVED MARKETING DIRECTION / CLAIMS REQUIRE EVIDENCE

## Core commercial principle

AgentOS should prominently market that it is designed to make the most of the AI a user already has available, including free AI, local AI and any paid AI the user already subscribes to.

Free AI is not merely a fallback. It is part of the core value proposition.

Working message:

> **AgentOS helps you get more from the AI you already have — including free AI.**

Secondary message:

> **Free AI is more powerful when it works together.**

## Product/commercial direction

AgentOS should be able to run effectively using free and local AI resources where those resources are sufficient for the user's jobs.

The $99/year Operator tier should be sold on two economic benefits:

1. **Save money** — use free/local capacity where suitable; use existing subscriptions/BYOK where available; avoid unnecessary use of paid resources when a free/local option is adequate.
2. **Save time** — coordinate AI selection, multi-step work, schedules, Night Shift, recurring work and other governed automation so the user spends less time choosing tools and manually managing workflows.

Recommended pricing framing:

> **$99 a year — less than $2 a week.**

Safer ROI framing until customer evidence exists:

> **AgentOS Operator only needs to save you a small amount of time or unnecessary AI spend each week to justify its cost.**

Do **not** currently publish an absolute guarantee that AgentOS will save every user more than $99/year.

## Homepage / landing-page messaging candidates

### Primary section

**Make the most of free AI**

You don't need a stack of expensive AI subscriptions to get useful work done.

AgentOS is designed to coordinate the free, local and paid AI available to you, choosing suitable capability for the job while respecting your preferences, limits, privacy and authority.

### Supporting message

**Your AI doesn't need to cost more. It needs to work better together.**

### $99 Operator message

**Less than $2 a week to put your AI to work.**

Operator should be positioned around broader schedules, Night Shift, recurring work, higher capacity, greater autonomy, stronger persistence and more extensive integrations, subject to implementation evidence.

## Evidence boundary

The following are OWNER/PRODUCT DIRECTION, not automatically verified implementation claims:

- AgentOS can run effectively using only free AI resources.
- AgentOS can optimise use of free, local and paid AI resources.
- AgentOS Operator saves users both money and time.

These should become public factual claims only after representative runtime testing supports them.

## Recommended proof programme

Create a repeatable **Free-AI Effectiveness Benchmark** using only legitimate free/local resources.

Test representative jobs across:

- research and summarisation
- document drafting
- planning
- coding / repository assistance
- structured extraction
- everyday personal tasks
- multi-step tasks
- scheduled/recurring work where implemented
- local/private tasks using Ollama where applicable

For each test record:

- job definition
- worker/provider used
- free/local/paid classification
- execution time
- user interaction time
- external AI spend
- outcome quality
- retries/failures
- Henry/PRS assurance result where applicable
- comparison against paid-resource execution where useful

## Success metrics

Marketing should seek evidence for:

- percentage of benchmark jobs completed acceptably with free/local resources only
- paid AI spend avoided on jobs where free/local resources were adequate
- user time saved versus manually choosing and coordinating AI tools
- incremental benefit of Operator automation/scheduling versus interactive-only use
- quality trade-offs between free/local and paid routes

## Claims ladder

### Safe now as positioning / design intent

- AgentOS is designed to make the most of free, local and paid AI.
- AgentOS is provider/model agnostic.
- Users should not need to replace their favourite AI to use AgentOS.
- $99/year is less than $2/week.

### Requires runtime evidence before strong factual marketing

- AgentOS runs effectively using only free AI.
- AgentOS consistently lowers AI spend.
- AgentOS saves a measurable amount of user time.
- AgentOS Operator pays for itself.

### Do not claim without robust evidence

- always cheapest
- always best model
- maximum quality
- zero wasted AI spend
- guaranteed savings greater than subscription price

## Strategic marketing significance

This is a core differentiator from products whose value proposition is primarily another paid AI subscription.

AgentOS should be positioned as the coordination layer that helps users make better use of the AI capacity they already possess.

Recommended core statement:

> **Use free AI. Use local AI. Use the AI you already pay for. AgentOS helps put it all to work together.**

## Governance

Affiliate, partnership or commercial relationships must never influence technical worker ranking. Routing remains based on capability, authority, privacy, health, availability, user preference, entitlement and cost.

No implementation, deployment, provider activation, credential change or production-autonomy authority is granted by this marketing record.
