# Portfolio Analysis Layer

The portfolio layer consumes repository-level state and findings to identify cross-repository relationships and systemic patterns.

It must link portfolio observations to supporting repository evidence and attach a confidence level to inferred relationships.

Default capabilities:

- repeated finding detection;
- dependency/version pattern detection;
- component reuse candidates;
- duplicated capability candidates;
- architecture conflicts;
- lifecycle signals;
- systemic risk aggregation.

Portfolio recommendations remain recommendations unless independently validated.
